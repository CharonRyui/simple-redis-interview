# 快照保留完整 AOF，以单文件原子发布保存检查点

在已有同步日志上增加手动 SAVE，快照保存当前数据、对应日志偏移及前缀 SHA-256，启动加载快照后只执行后续日志。保留完整 AOF 而不在保存时截断日志，避免快照发布和日志切换之间需要多文件提交协议；代价是快照不能脱离匹配日志单独恢复，磁盘日志继续增长，启动仍需读取旧日志前缀做校验。

SAVE 持有全局写锁，流式写入同目录临时文件、同步后原子替换并同步目录，接受保存期间阻塞其他存储操作，以保证快照状态和截止偏移一致。正式快照损坏或与日志不匹配时拒绝启动；未发布的临时文件不参与恢复。后续若需要日志压缩或独立快照导入，应另行设计日志代次与发布协议。
